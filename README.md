# Business Awareness Wall — Colour Blindness in Football

Official public awareness and sponsorship project by Cornelius Aurelius.

## What the website is

The site supports awareness of colour vision deficiencies in football and promotes the existing 12,000 Pixel supporter wall and voluntary fundraising for free books. It is **not** the pixel supporter registry itself, nor an accounting dashboard.

## Added educational activity

**The Kit Signal Challenge** is an original eight-decision, untimed, keyboard- and touch-friendly quiz designed to explain why numbers, symbols, kit brightness and equipment contrast matter in football. Personal-best score is stored only on the visitor's device. A side-by-side kit-cue illustration is intentionally not a medical vision simulation.

## Data integrity

Live fundraising totals and sponsor lists require authorised, verified records. Until such a data source is connected, the website shows a clear notice and does **not** claim a £0 live balance or display fictional sponsor names.

Do not automatically sync private Stripe information into a public static website without proper permissions and privacy safeguards. All existing sponsorship/payment links and the main book/project/pixel links remain unchanged.
